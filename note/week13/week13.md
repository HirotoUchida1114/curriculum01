## 1. コマンドの順序
* pnpm create viteでプロジェクトの骨組みをつくり、pnpm installで必要なものをダウンロードし、pnpm run devでパソコン内で動くブラウザを立ち上げ、pnpm run buildで最終成果物を書き上げた。

## 2. vite.config.js に base: './' を設定した理由（設定しないと何が起きるか）
* 絶対パスではなく相対パスとして入力するため。そう入力すると正しく読み込めず、真っ白になってしまう。
