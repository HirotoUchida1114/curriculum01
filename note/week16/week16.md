## 4. 自分で理解していない箇所が無いことの確認
* **理解していない箇所:** 括弧の種類
* **（ ）:** ・イベントの実行や計算の実行
* **{ } :** ・JavaScriptの処理のまとまり: if 文の条件を満たしたときの処理や、ボタンを押したときに動かす処理の「中身全体」を囲む。
cSSのスタイル指定: .animate-shake { animation: shake 0.6s; } のように、どのデザインを適用するかの中身を囲む。
* **[ ]:** ・リスト（配列）の作成: const omikujiData = [ 大吉のデータ, 中吉のデータ, ... ]; のように、複数あるデータを一列に並べて保存するときに使う。
・データの指定（インデックス）: omikujiData[randomIndex] のように、リストの中の「何番目のデータを引き出すか」を指定するときに中にお札（番号）を入れます。
* **< >:** HTMLタグの作成
